# Héritage de Grâce

Petit site vitrine de départ pour un projet de littérature chrétienne réformée francophone. Il est volontairement construit en HTML, CSS et JavaScript simples : aucune installation ni dépendance n’est nécessaire.

## Voir le site

Ouvrez `index.html` dans un navigateur. Pour le publier gratuitement, vous pourrez ensuite activer GitHub Pages dans **Settings → Pages**, en choisissant la branche `main` et le dossier `/ (root)`.

## Personnaliser

- Modifiez les textes et les cartes de lecture dans `index.html`.
- Changez les couleurs, la mise en page et les polices dans `styles.css`.
- La recherche et les filtres sont dans `script.js`.
- Remplacez `contact@example.com` par votre adresse de contact.

Les cartes actuelles sont des exemples de présentation, pas des textes publiés. Avant d’ajouter une œuvre, vérifiez son auteur, son édition, sa traduction et les droits applicables en France. Le fait qu’un texte ancien soit dans le domaine public ne signifie pas automatiquement que toute traduction ou édition moderne l’est aussi. Ajoutez les références bibliographiques et les mentions de droits à chaque publication.

## Idées pour la suite

1. Choisir les premières œuvres et vérifier les droits de publication.
2. Remplacer les exemples par de vraies fiches : titre, auteur, date, source, durée de lecture et texte.
3. Ajouter une page dédiée par texte, puis une navigation par auteur et par thème.
4. Demander à quelques lecteurs de tester le site sur téléphone et ordinateur.
